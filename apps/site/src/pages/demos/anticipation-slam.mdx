## Anticipation

`ReelSet.setAnticipation([4])` tells reel 5 to enter an ANTICIPATION phase
before STOP. Use it when the grid so far *could* still become a big win.

```ts
const promise = reelSet.spin();
setTimeout(() => {
  const scatters = countScattersSoFar(response.symbols.slice(0, 3));
  if (scatters === 2) reelSet.setAnticipation([3, 4]);
  reelSet.setResult(response.symbols.map((visible) => ({ visible })));
}, 200);
```

## Slam-stop (skip)

`ReelSet.skipSpin()` force-lands every reel onto the target from
`setResult()`. The returned `SpinResult` has `wasSkipped: true`.

It **throws** if the result has not arrived yet -- there is nothing to land
on. For a spin/skip button, use `requestSkip()`, which slams now or queues
the intent until `setResult()` lands. That is what this demo does: it waits
240 ms for its mock server, and a second click inside that window would
throw.

```ts
spinButton.addEventListener('click', () => {
  if (reelSet.isSpinning) reelSet.requestSkip();
  else reelSet.spin();
});
```

## Cheats on this page

- **Force anticipation on reels 4+5** (default on). every spin slow-holds the last two reels.
- **Near-miss**. 2 scatters visible, reel 5 blanks, anticipation still fires.
- **Full 3-scatter trigger**. the anticipation pays off.
