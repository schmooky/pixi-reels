Press Spin. Both strips spin, then land on a fresh set of the round's paying
symbols. This is the banner *above* the reels — one row, oriented sideways — not
the reels themselves.

## Same contract as `ReelSet`

A banner reel is still a reel: you spin it, hand it the server's result, and it
lands. `HorizontalReel` follows the exact `ReelSet` flow, one row wide:

```ts
const strip = new HorizontalReelBuilder()
  .visibleCount(5).cellSize(64, 64, { gap: 8 })
  .direction('rtl').scroll(26)
  .symbols((r) => { for (const c of CARD_DECK) r.register(c.id, CardSymbol, c); })
  .ticker(app.ticker)
  .build();
app.stage.addChild(strip.container);

const spin = strip.spin();          // starts scrolling, returns a promise
strip.setResult(await server.pay);  // ['A','K','Q','J','10'] — one per visible cell
const { symbols } = await spin;     // resolves when it lands on exactly that
```

`spin()` / `setResult(ids)` / `skipSpin()` / `isSpinning` and the `spin:start` /
`spin:complete` events all mirror `ReelSet`. The only shape difference is that
`setResult` takes a flat `string[]` of `visibleCount` ids (one row) instead of a
`ColumnTarget[]` grid.

## Why it's a separate class

The engine's `Reel` wraps symbols on the **Y** axis and bakes that in throughout
(`ReelMotion`, the stop sequencer, buffer rows). A sideways reel is a different
axis, so `HorizontalReel` is a focused mechanism on the same shared primitives
(the symbol pool, `TickerRef`, the typed `EventEmitter`) — it just exposes the
familiar reel API on top.

## Two spin motions: scroll and cascade

| Mode | Call | Feel |
|---|---|---|
| `scroll` | `.scroll(pxPerFrame)` | smooth, decelerating spin (default) |
| `cascade` | `.cascade({ interval, duration })` | stepped one-cell reveal — the tumble on its side |

Both honour `direction`: `rtl` scrolls leftward, `ltr` rightward, and `setResult`
lands the same symbols either way.

## The surface

| Member | Use |
|---|---|
| `spin()` | start spinning; resolves with the landed `{ symbols }` |
| `setResult(ids)` | the round's paying symbols, one per visible cell; triggers the stop |
| `skipSpin()` | slam straight to the pending result |
| `isSpinning` | lifecycle state |
| `symbolAt(slot)` | the live `ReelSymbol` in visible slot `slot`, left→right |
| `events` | `spin:start`, `spin:complete ({ symbols })` |
| `destroy()` | drops the ticker subscription and pooled instances |
