<a id="cell-hit-areas"></a>

## Cell hit areas. click to pick, hover to preview

Attach pointer events to individual cells with getCellBounds; hover previews, click toggles a pick, picks survive spins.

**Gotcha:** fill the hit rect with alpha 0, not `visible = false`. an invisible-but-filled rect is still hit-testable; a hidden one is not.

## Horizontal strip motion blur

The same cached-snapshot spin on a HorizontalReel, with the smear following the sideways travel.

**Gotcha:** pass `blur: { axis: 'x' }` to both prewarmSpinTextures and the symbol options, and give the strip its own SpinTextureCache (its cell geometry differs from the main grid).

## Roll-up (reverse direction)

Every reel spins upward: one `.direction('reverse')` call. New in v2 - direction lives on the orientation axis, so the same engine, events and landing bounce just run the other way.
