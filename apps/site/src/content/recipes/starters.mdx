Each starter is a small working slot. The line slots come first, then the other common layouts, then the symbol pools that control what the reels draw while they spin.

<a id="starter-horizontal-5x3"></a>

### Horizontal

The same template with the reels turned sideways. Three reels are stacked down the screen and each one scrolls along x. The change is one call, `.orientation('horizontal')`, plus the cell size you want on screen.

`symbolSize(w, h)` and `symbolGap(x, y)` stay in screen space. On a horizontal set the strip advances by the symbol width, `x` is the gap between cells and `y` is the gap between reels. Index space does not change, so `reels(3).visibleCells(5)` and the `ColumnTarget[]` you pass to `setResult()` stay the same.

<RecipeDemo code="starter-horizontal-5x3" />

<a id="starter-reverse-5x3"></a>

### Reverse

The classic 5x3 with the reels running the other way. Symbols rise and each reel lands from below. The only change from the classic starter is `.direction('reverse')`.

Buffers stay geometric. `bufferStart` is still the slot above the window, so on a reverse reel the next symbol to come in sits in `bufferEnd`. Read `reel.axis.feedEdge` instead of assuming. See [orientation and direction](/mechanics/orientation-and-direction/#roll-up) for per-reel and mixed-axis setups.

### MultiWays

Each reel lands on its own number of cells between `minCells` and `maxCells` on each spin. The number of ways is the product of the per-reel cell counts.

Call `reelSet.setShape(rowsPerReel)` before `setResult()`, with `serverGrid[i].length === rowsPerReel[i]`.

## Which symbols may spawn where

`weights()` is one table for the whole set. A pool is layered on top of it for a scope, which can be one reel, the buffer cells, or the buffer cells of one reel. A pool changes only the random draw. An explicit `setResult` target always wins.

### Keep a symbol out of the buffers

Each spin moves to the next pool state. First there is no pool, then COIN is kept out of the buffers of reel 1 (the second reel, since indices start at 0), then out of the buffers above the window, then out of all buffers. The labels above and below the grid show what the hidden cells hold, so you can watch COIN stop parking there.

### A draw table per reel

Each reel can have its own draw table. Watch the spin, not the landing. Reel 0 draws low cards only, reel 2 is mostly wilds while it scrolls, and reel 4 never draws a wild. All five share the same `weights()` underneath.
